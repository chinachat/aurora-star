# Markdown 发布器示例文章

这篇文章是 **Markdown** 语法的示例，导入后会自动转换成 HTML 文章。
支持 *斜体*、**加粗**、***加粗斜体***、~~删除线~~、`行内代码`，以及脚注[^1]。

[TOC]

## 一、基本语法

### 1.1 列表

无序列表：

- 第一项
- 第二项
  - 嵌套子项
  - 另一个子项

有序列表：

1. 打开 WordPress 后台
2. 进入「Markdown 发布器 → 导入 Markdown」
3. 上传 `.md` 文件

任务列表：

- [x] 支持 Markdown 语法
- [x] 支持 `.md` 文件导入
- [ ] 支持更多自定义样式

### 1.2 引用与分隔线

> 提示：Markdown 原文会保存在文章元数据中，
> 随时可以回到后台继续编辑。

---

## 二、表格与链接

| 功能 | 语法 | 说明 |
| :--- | :---: | ---: |
| 标题 | `# 标题` | 自动生成锚点 |
| 链接 | `[文字](https://example.com)` | 支持引用式链接 |
| 图片 | `![说明](图片地址)` | 支持 alt 文本 |

行内链接示例：[WordPress 官网](https://wordpress.org "WordPress")，
引用式链接示例：[Markdown 规范][spec]，自动链接：https://cn.wordpress.org

[spec]: https://spec.commonmark.org/ "CommonMark 规范"

## 三、代码块

```php
<?php
// 保存文章时把 Markdown 渲染成 HTML
$parser = new Mdp_Markdown();
$html   = $parser->toHtml( $markdown );
```

```bash
# 使用 WP-CLI 批量重新渲染
wp mdp rerender --post_type=post
```
